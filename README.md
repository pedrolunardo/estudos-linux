Anotações do meu estudo de Linux, redes e nuvem.

## Projeto: Diagnóstico de Rede Linux

Projeto prático para estudar Linux e Redes de Computadores.

### O que o script verifica

- Interfaces de rede e endereços IP
- Rota padrão
- Conectividade com o endereço 1.1.1.1
- Resolução DNS de google.com

### Requisitos

- Linux
- Bash
- iproute2
- iputils-ping
- getent

### Como executar

No terminal, dentro da pasta do projeto:

```bash
bash diagnostico.sh
```

### Objetivo

Praticar comandos Linux e documentar procedimentos básicos de diagnóstico de rede.

## Estudos

Anotações diárias do meu estudo de Linux e redes. Dia 01: terminal e comandos básicos.
